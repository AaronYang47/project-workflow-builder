# L5 factory playback

The factory uses a 2D floor plan. The production line places each module across
two parallel roller tracks at its simulated progress. The yard view shows
occupied bays, modules in transit and pickups on the selected day. Bay numbers
are display positions because the simulation stores yard counts per project.
